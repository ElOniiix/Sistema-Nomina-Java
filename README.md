# 💼 Sistema de Gestión y Liquidación de Nómina (Java)

Sistema de consola (CRUD) desarrollado en Java puro, diseñado para administrar empleados y liquidar la nómina mensual aplicando la normativa laboral colombiana.

## 🚀 Características Principales
*   **CRUD Completo:** Registro, consulta, actualización y eliminación de empleados utilizando `ArrayList`.
*   **Programación Orientada a Objetos (POO):** Clases encapsuladas (`Empleado`), separación de lógica de negocio (`CalcularNomina`) y gestión de constantes.
*   **Validación Estricta:** Manejo de excepciones (`try-catch` con `NumberFormatException`) y validaciones cíclicas para evitar caídas del sistema por errores de usuario.
*   **Formateo Local:** Salida de datos en consola formateada bajo el estándar de moneda colombiana (`es-CO`).

## 🛠️ Tecnologías Utilizadas
*   Java (JDK)
*   Estructuras de datos dinámicas (ArrayList)
*   Librerías nativas (`java.util.Scanner`, `java.util.Locale`)
